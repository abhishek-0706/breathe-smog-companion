Describe the changes/updates made in the deployed version:
Breathe combines real Open-Meteo/CAMS modeled outdoor data, household preferences, low-emission routines, indoor-air guidance and transparent CO2 scenarios. Gemini provides contextual explanations, with labeled sourced safety and reference responses. Refactored the UI, domain logic, request handlers and provider adapters into focused modules. Added strict JavaScript type checking, architecture boundaries and a maximum function complexity of 15, enforced by CI with formatting and lint checks. Verified 110 automated tests, unchanged outputs for 30 golden cases and 120 routine combinations, 82 browser checks, 14 automated accessibility audits with no violations, and 30 live production checks across all nine cities. GitHub CI/CodeQL pass; no open security alerts or known dependency advisories. See VALIDATION.json for scope.

Gen AI services and usage:
Google Gemini powers contextual clean-air chat from normalized household preferences, bounded recent conversation and server-fetched modeled air data. The API key remains in Vercel server environment variables. Safety-critical questions receive labeled sourced guidance; provider fallback is labeled. Open-Meteo/CAMS supplies modeled environmental data and is not GenAI. Generative answers may contain errors and do not replace official alerts or medical care.
